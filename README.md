## 📖 About Project

Expense Tracker is a Python-based command-line application developed to help users manage and organize their daily expenses.

The application allows users to add, view, edit, delete, search, sort, and export expense records. All data is stored in JSON format and can be exported to CSV files for further analysis.

## ▶️ How to Run


```bash

```

3. Run the program

